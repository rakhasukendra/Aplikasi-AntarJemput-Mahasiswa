# UI audit 001 - 2026-11-16

Scope: passenger booking, trip tracking, and the supplied mobile screenshots. The requested direction is a map-led campus ride app with green actions/status and warm, light surfaces, inspired by the references without copying Gojek branding.

## Findings

1. **HIGH - R-02: Em dashes in the map instructions.** `lib/screens/passenger/passenger_home_tab.dart` joins the map prompts with the em dash character (U+2014). Replace it with punctuation that follows the copy rule.
2. **MEDIUM - R-01/R-29: App colors conflict with the reference direction.** `lib/main.dart` uses navy as the primary color and a cool grey scaffold background, while the screenshots use green for key actions/status and a warm, pale base. Set a consistent, restrained palette across the passenger flow.
3. **LOW - R-05/R-20: Booking layout gives the map limited emphasis.** `PassengerHomeTab` fixes the map to about 36% of the screen and places the multi-step form in a separate scrolling area. The references make location and route context the visual anchor; consider a map-led layout with the booking controls grouped in an attached panel.
4. **LOW - R-05/R-20: Tracking separates the map from the trip status.** `TripTrackingScreen` limits the map to 310px and places status, timeline, and route details below it in a scrolling list. The reference keeps the map dominant and groups live progress in a panel over it; adapt that structure while retaining the existing trip states and real data.
